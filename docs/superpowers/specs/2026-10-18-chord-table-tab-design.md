# コード表タブ: ボタンから押さえ方を引く

2026-10-18

## 背景

今の web には押さえ方を見る経路が2つある。

- **プレビュータブ** — エディタに書いた進行のコードを図にする。進行を書かないと何も出ない
- **エディタタブの指板** — 指板をクリックして作った形から**コード名を引く** (逆引き)

逆の「コード名から押さえ方を見たい」経路が無い。`C#m7` の押さえ方を知りたいだけのとき、
エディタに `C#m7 |` と打ってプレビュータブに移る必要がある。

## 画面

タブを1つ足す。

```
[エディタ] [プレビュー] [コード表]

┌─────────────────────────────────────────────┐
│        (maj)  m    7   m7   M7  m7b5 sus4 … │
│  C      [ ]  [ ]  [ ]  [ ]  [ ]  [ ]  [ ]   │
│  C#     [ ]  [ ]  [ ]  [ ]  [ ]  [ ]  [ ]   │
│  D      [ ]  [ ]  [ ]  [ ]  [ ]  [ ]  [ ]   │
│  …                                          │
├─────────────────────────────────────────────┤
│  Am7                                        │
│  1弦 x |---|---|---|---|---|                │
│  2弦 1 |-●-|---|---|---|---|   ← 表示専用    │
│  …                                          │
└─────────────────────────────────────────────┘
```

- 格子は **12ルート × 11品質**
- ボタンを押すと、下の指板にその押さえ方が出る
- 指板は**表示専用**。クリックできない。逆引きはエディタタブの指板に残す
- 記法の挿入はしない。見るだけのタブ

## 品質の列

`identify` の `QUALITIES` と同じ並びから、ボタンの行が長くなりすぎないよう
よく使うものを選ぶ。

| 列 | 記法 | 例 |
|---|---|---|
| (maj) | (無し) | `C` |
| m | `m` | `Cm` |
| 7 | `7` | `C7` |
| m7 | `m7` | `Cm7` |
| M7 | `M7` | `CM7` |
| m7b5 | `m7b5` | `Cm7b5` |
| sus4 | `sus4` | `Csus4` |
| 6 | `6` | `C6` |
| add9 | `add9` | `Cadd9` |
| dim | `dim` | `Cdim` |
| aug | `aug` | `Caug` |

ルートは `C C# D D# E F F# G G# A A# B` の12個。合わせて132ボタン。

## 押さえ方の引き方

**新しい探索ロジックは書かない。** ボタンのラベルからコード名の文字列を組み、
既存の公開 API をそのまま通す。

```
"C#" + "m7" → "C#m7 |\n"
  → RechordImporter::import
  → Expr::resolve
  → fingering::chord_refs
  → fingering::shape_of   // tab 記法の PR で足した所有型を返す関数
  → Option<Shape>
```

1クリックにつきパース1回。132個を先読みはしない (押されたものだけ引く)。

`shape_of` が `None` を返す組み合わせでは「押さえ方データなし」と出す。

**設計時は「引けないボタンを薄く表示する」としていたが、実装前に132通りを
計測したところ全部引けた**ので落とした。`find` は「余計な音1つまで許容」の
近似検索なので、どんなコード名でも必ず何かを返す。薄くなるボタンが1つも
無い以上、その判定のための132回のパースごと要らない。

近似かどうかは詳細欄の `(≒ 原典名)` の有無で分かる (原典にその名前の形が
あるのは26/132で、残りは別のコードの形での代用)。

## 指板コンポーネント

今の `Fretboard` は「クリック → 逆引き → 挿入」専用で、表示専用の使い方ができない。
マス目を描いているのは `fretboard.rs` の `board()` 関数なので、ここに
`readonly` を足す。

```rust
/// マス目を描く。`on_change` が `None` なら表示専用で、マスを
/// `<button>` ではなく `<div>` で描く。コード表タブは押さえ方を
/// 見るだけなので、押せる見た目にしない
fn board(frets: [Option<u8>; 6], on_change: Option<&Callback<[Option<u8>; 6]>>) -> Html
```

`readonly` のフラグと `on_change` を別々に渡すと「読み取り専用なのに
コールバックがある」という組み合わせが型の上で作れてしまうので、
`Option` 1つにまとめる。

エディタタブの指板 (`Fretboard` コンポーネント) の見た目と挙動は変えない。
コード表タブは `board()` を直接呼ぶ。

## 表示するもの

ボタンを押した後、指板の上にコード名を出す。`Shape::name` が `Some` で
コード名と違うときだけ `(≒ 原典名)` を併記する。プレビューの図と同じ規則。

まだ何も押していないときは「コードを押すと押さえ方が出ます」と出す。

## 亜種の選択

格子でコードを選ぶと、その下に**そのコードの押さえ方の亜種**がボタンで
並ぶ。押した亜種が指板に出る。

```
格子で C を選ぶ
  ↓
[指2本] [指3本] [パワー (6弦ルート)] [パワー (5弦ルート)]
        [オクターブ (6弦ルート)] [オクターブ (5弦ルート)]
  ↓ 押す
指板にその形
```

### 亜種に並ぶもの

1. **原典にある同名の形**。`kind == Normal` で `name` がコード名と一致する
   もの全部。押さえる指の少ない順に並べる
2. 原典に同名の形が無ければ、代わりに **`find` の近似を1つ**。ラベルは
   `近似 (≒ 原典名)`
3. **可動形**。ルートのピッチクラスが一致する `Power` と `Octave` の形。
   それぞれ6弦ルートと5弦ルートの2本ずつ

### ラベル

原典の形は**押さえる指の本数**で呼ぶ (`指2本` `指3本`)。

「通常 / 簡単」とは呼ばない。原典のデータにその区別は入っておらず、
指の本数から機械的に決めると嘘になるため。同名の形が2つあるのは5種だけで、
その内訳は次の通り。

| コード | 形 | 指 |
|---|---|---|
| C | `x-3-2-0-1-x` / `x-3-x-0-1-x` | 3本 / 2本 |
| C/E | `0-3-2-0-1-x` / `x-x-2-0-1-x` | 3本 / 2本 |
| D | `x-x-0-2-3-2` / `x-x-0-2-3-x` | 3本 / 2本 |
| Em7 | `0-2-0-0-0-0` / `0-2-0-0-3-x` | 1本 / 2本 |
| G | `3-x-0-0-0-x` / `3-x-0-0-3-x` | 1本 / 2本 |

`Em7` と `G` は**指が一番少ない形こそが標準形**で、「簡単な方」と呼ぶと
誤解を招く。指の本数を出せば、左ほど押さえやすいことがそのまま伝わる。

### 状態

```rust
/// 格子で選んだコード。`(ROOTS の添字, QUALITIES の添字)`
type Picked = Option<(usize, usize)>;
```

亜種の選択は `usize` の添字で別に持つ。コードを選び直したら 0 に戻す。

### 簡単コードモードは廃止

原典の形は亜種のボタンから引けるようになるので、「格子 / 簡単コード」の
切り替えと一覧は消す。タブの中は格子 → 亜種 → 指板の1本道になる。

## 指番号

`board()` に `fingers: [Option<Finger>; 6]` を足し、ドットの中に
`人 / 中 / 薬 / 親` を描く。小さいコード図 (`ChordDiagram`) は既に
描いているので、見た目の規則はそれに合わせる。

エディタタブの指板は `[None; 6]` を渡す。自分で押した形には指のデータが
無いので、見た目は今までと変わらない。

## やらないこと

- 記法の挿入 (見るだけのタブ)
- コード表タブの指板をクリックできるようにすること
- 原典にある形を名前で一覧すること (亜種はコードを選んでから出す)
- 度数表記 (`I` `VIm`) のボタン。キーに依存するのでコード表には馴染まない
- CLI への対応
