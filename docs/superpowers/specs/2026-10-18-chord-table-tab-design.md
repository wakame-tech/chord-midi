# コード表タブ: ボタンから押さえ方を引く

2026-10-18

## 背景

今の web には押さえ方を見る経路が2つある。

- **プレビュータブ** — エディタに書いた進行のコードを図にする。進行を書かないと何も出ない
- **エディタタブの指板** — 指板をクリックして作った形から**コード名を引く** (逆引き)

逆の「コード名から押さえ方を見たい」経路が無い。`C#m7` の押さえ方を知りたいだけのとき、
エディタに `C#m7 |` と打ってプレビュータブに移る必要がある。

## 画面

タブを1つ足す。

```
[エディタ] [プレビュー] [コード表]

┌─────────────────────────────────────────────┐
│        (maj)  m    7   m7   M7  m7b5 sus4 … │
│  C      [ ]  [ ]  [ ]  [ ]  [ ]  [ ]  [ ]   │
│  C#     [ ]  [ ]  [ ]  [ ]  [ ]  [ ]  [ ]   │
│  D      [ ]  [ ]  [ ]  [ ]  [ ]  [ ]  [ ]   │
│  …                                          │
├─────────────────────────────────────────────┤
│  Am7                                        │
│  1弦 x |---|---|---|---|---|                │
│  2弦 1 |-●-|---|---|---|---|   ← 表示専用    │
│  …                                          │
└─────────────────────────────────────────────┘
```

- 格子は **12ルート × 11品質**
- ボタンを押すと、下の指板にその押さえ方が出る
- 指板は**表示専用**。クリックできない。逆引きはエディタタブの指板に残す
- 記法の挿入はしない。見るだけのタブ

## 品質の列

`identify` の `QUALITIES` と同じ並びから、ボタンの行が長くなりすぎないよう
よく使うものを選ぶ。

| 列 | 記法 | 例 |
|---|---|---|
| (maj) | (無し) | `C` |
| m | `m` | `Cm` |
| 7 | `7` | `C7` |
| m7 | `m7` | `Cm7` |
| M7 | `M7` | `CM7` |
| m7b5 | `m7b5` | `Cm7b5` |
| sus4 | `sus4` | `Csus4` |
| 6 | `6` | `C6` |
| add9 | `add9` | `Cadd9` |
| dim | `dim` | `Cdim` |
| aug | `aug` | `Caug` |

ルートは `C C# D D# E F F# G G# A A# B` の12個。合わせて132ボタン。

## 押さえ方の引き方

**新しい探索ロジックは書かない。** ボタンのラベルからコード名の文字列を組み、
既存の公開 API をそのまま通す。

```
"C#" + "m7" → "C#m7 |\n"
  → RechordImporter::import
  → Expr::resolve
  → fingering::chord_refs
  → fingering::shape_of   // tab 記法の PR で足した所有型を返す関数
  → Option<Shape>
```

1クリックにつきパース1回。132個を先読みはしない (押されたものだけ引く)。

`shape_of` が `None` を返す組み合わせ (`find` のフィルタをどの形も通らない) では
「押さえ方データなし」と出す。どのボタンが引けるかは押すまで分からないので、
**初回表示時に全132通りを1度だけ引いて、引けないボタンを薄く表示する**。
132回のパースは一瞬で、`use_memo` で1回に抑える。

## 指板コンポーネント

今の `Fretboard` は「クリック → 逆引き → 挿入」専用で、表示専用の使い方ができない。
マス目を描いているのは `fretboard.rs` の `board()` 関数なので、ここに
`readonly` を足す。

```rust
/// `readonly` ならマスを <button> ではなく <div> で描く。
/// コード表タブは押さえ方を見るだけなので、押せる見た目にしない
fn board(frets: [Option<u8>; 6], readonly: bool, on_change: &Callback<[Option<u8>; 6]>) -> Html
```

エディタタブの指板 (`Fretboard` コンポーネント) の見た目と挙動は変えない。
コード表タブは `board()` を直接呼ぶ。

## 表示するもの

ボタンを押した後、指板の上にコード名を出す。`Shape::name` が `Some` で
コード名と違うときだけ `(≒ 原典名)` を併記する。プレビューの図と同じ規則。

まだ何も押していないときは「コードを押すと押さえ方が出ます」と出す。

## やらないこと

- 記法の挿入 (見るだけのタブ)
- コード表タブの指板をクリックできるようにすること
- 同じコードに複数ある押さえ方を並べること。`shape_of` が返す1つだけを出す
- 度数表記 (`I` `VIm`) のボタン。キーに依存するのでコード表には馴染まない
- CLI への対応
