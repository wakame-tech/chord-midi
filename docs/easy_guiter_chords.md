# 超簡単コード一覧（押さえ方）

出典: <https://daichan-easyguitar.com/easychord-list/>

> このファイルは `scripts/gen_fingerings.py` が `easy_guiter_chords.json` から生成する。手で編集しない。

## 条件

- バレーコードなし
- 指1~3本で抑えられる
- 小指は使わない

## 記法

- 押さえ方は **6弦→1弦** の順で表記（例: `x32010`）
- 数字はフレット番号、`0` は開放弦、`x` はミュート
- チューニングは標準 (E A D G B E)
- 運指は 人=人差し指 / 中=中指 / 薬=薬指 / 親=親指。原典に指の指定が無いため規則で導出している

同じコード名が複数ある場合は、原典に載っている複数の押さえ方（難易度・響きの違い）を並べたもの。

HTML 表示用の同じデータは [`easy_guiter_chords.json`](./easy_guiter_chords.json) にある。
